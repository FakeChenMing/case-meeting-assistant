# 使用说明

1. 双击桌面启动入口。已安装私人0.2.4的用户继续用原入口；新安装公开版使用“启动案件沟通辅助-公开版.command”。
2. 首页选择案件目录及其内部会前包，点击“读取交接并创建专用会话”。等材料实际读取完成；材料缺失时补齐，再重新核对。单机的会前包也由本机准备。
3. 核对案件、专用会话、模型。需要换模型时刷新列表，选择模型及推理，再点应用；下拉选择本身不生效。已在途/排队回合保留原选择。
4. 点击“开始持续录音与辅助”。确认实际采样和新转写出现再说话。45秒虚构按钮用于短测并自动停止。普通持续模式须主动结束。
5. 查看最多五条追问，按已问/已解决/稍后/本次不问处理。候选池、已处理、恢复建议和阶段摘要可展开。按钮不是案件处理决定。
6. 点击转写文字回听原音频；识别错了点“纠正识别文字”，修改并保存。原始文字和历史保留，受影响分析先标待更新。听不清时标待核。
7. “随时提问”独立保存问题和回答；选择“记录我的明确处理决定”可保存自己的明确指示。不要把AI建议或未知说话人的话当作决定。
8. 暂停分析仍可能录音，继续分析会处理积压。故障、权限和提交未知时看状态，不反复点开始。关闭浏览器不会替您停止采集。
9. 点击“结束并生成交接”，等待尾段、剩余分析和整场整理。保存后自动返回空白首页，历史保留。会后包保持draft，核对后再接手。
10. 从历史沟通查看旧内容；历史默认只读。续录要点“继续这次沟通”；换案件回首页重新选。单机同机接手，双机核对下载后接手；正式文书修改另行确认。

产物在案件目录`沟通记录-GPT/<本次会话>/`，会后版本保留为v001、v002等。运行数据库及源录音留本机，已封闭音频随交接清单回查。公开教程的所有案件和会话标识均为虚构。

当前预览不支持系统音频和远程会议，中文关键字仍可能识别错；需要持续真人录音、耳机和网络故障等验收后才能判断正式现场适用性。功能图解不是验收证明。
